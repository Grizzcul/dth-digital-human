## 2. 已实现但仍需人工或集成复核

这些项没有被视为“未开发”，但自动化模拟不能证明真实设备和服务的全部表现。

| 检查项 | 需要确认 |
| --- | --- |

| 真实模型停止 | 当前供应商是否及时响应停止；不能据确认响应推断计费终止 |

| 音质与连续性 | 设备冷启动、句间停顿、蓝牙输出延迟、长回答与停止 |

## 4. 已知维护事项

- `setup.ps1` 末尾提示泛称 `API_KEY`，实际应按模板填写 `DIFY_API_KEY` / `DOUBAO_TTS_API_KEY`。本轮只整理文档，未改启动脚本。
- `tools/diagnose_latency.py` 默认诊断依赖登记表首个 WebM（目前为 `png/avatar.webm`）。其 `--live` 在收到 `workflow_finished` 时结束读取，没有使用主链路的双结束条件；用于严格成功判定前需复核，不能替代主链路 SSE 验收。
- 所有静态文件目前 no-store；尚无协商缓存。页面消息 DOM 无分页，刷新不恢复可见历史。
- 语音按片段精确匹配缓存；流到达节奏不同可能使普通回答分段不同，从而降低命中。测试准备与播放共用分句器。
- 浏览器关闭会停止本机播放，但没有完整的模型任务离开页面取消流程；后端服务继续运行。
- JSON / NDJSON / SQLite 与上游读流有显式边界限制，当前不是多人并发容量承诺。
